# 건지울른스

바다 스웨터의 헤리티지를 오늘의 일상에 옮기는 코튼 니트 브랜드 홈페이지입니다.

## 구성

- 홈 / 내 소개 / 제품 / 이야기 / 연락하기
- 순수 HTML, CSS, JavaScript
- 모바일 반응형 레이아웃
- 키보드 탐색 및 모션 감소 설정 지원

## 로컬에서 보기

별도의 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 사용하려면 아래 명령을 실행할 수 있습니다.

```bash
python -m http.server 8000
```

그 다음 `http://localhost:8000`으로 접속합니다.

## 수정하기

- 페이지 내용: `index.html`
- 색상과 레이아웃: `styles.css` 상단의 CSS 변수
- 메뉴와 이메일 폼 동작: `script.js`
- 제품 이미지: `assets/guernsey-crewneck.png`

이메일 신청 폼은 현재 화면에서만 완료 메시지를 보여주는 데모입니다.
